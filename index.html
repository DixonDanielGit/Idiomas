What is Java?

Java is a general-purpose programming language. Java code is compiled and can run on different systems through the Java Virtual Machine, known as the JVM.

Explore short examples and an interactive exercise. No prior experience is needed: start by learning how data is stored and used.

A brief history

Java was developed at Sun Microsystems and introduced to the public in 1995. Oracle acquired Sun Microsystems in 2010. Since then, Java has continued to evolve with contributions from Oracle and the community behind OpenJDK.

Where can you use Java?

  • Android apps: Java supports Android development alongside Kotlin and other tools in the ecosystem.
  • Video games: Minecraft: Java Edition is a well-known example of a PC game developed with Java.
  • Desktop tools: Eclipse IDE and other tools use extensible platforms built primarily with Java.
  • Web services: Build APIs and backend systems with Java and tools such as Spring.

What makes Java distinctive?

  • Cross-platform: the same program can run on systems with a compatible JVM.
  • Statically typed: when declaring a variable, you specify the type of data it will hold.
  • Object-oriented: the language lets you organize programs into classes and objects.

Variables and data types

A variable is a name associated with a value. In Java, a declaration includes the type, the name, and optionally an initial value.

Methods: named actions

A method groups instructions to perform a task. In Java, methods are declared inside a class and run when the program calls them; they are not written as standalone functions outside a class.

A method that says hello 
public class Greeting {
    public static void main(String[] args) {
        greet("Lina");
    }

    static void greet(String name) {
        System.out.println("Hello, " + name);
    }
}
