# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

People who are new to programming and want to learn Java without assuming prior experience.

## Product Purpose

An English-language guide introducing Java, familiar applications built with it, and its core concepts. Readers should recognize where Java is used, explain what it is, and understand simple examples of variables, data types, and methods.

## Capabilities and Constraints

- Static web page built with HTML, CSS, and JavaScript.
- Briefly explains Java's history, features, common uses, variables, data types, methods, and examples.
- Includes an accessible carousel with original Java-inspired branding and illustrative images of games, desktop tools, and web services.
- Includes copyable code examples and a small interactive exercise for beginners.
- Offers light and dark themes, remembers the selected theme, and uses a responsive layout.
- Presents all interface text and explanations in English and asks browsers not to translate the page.
- Automatically advances the carousel while it is visible, unless the visitor pauses it or prefers reduced motion.

## Brand Commitments

- Use Java-inspired colors, with warm tones and orange actions.

## Product Principles

- Explain concepts in plain language and define technical terms.
- Teach with short examples that follow Java syntax.
- Present named products as examples without implying illustrative photos are official screenshots.
- Distinguish Java methods from standalone functions in other languages.
- Keep reading comfortable on small screens and in both themes.
- Keep the carousel controllable, pause it during interaction, and respect reduced-motion preferences.
